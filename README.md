# Minh Hưng Agency – website

Landing page tĩnh (HTML/CSS/JS thuần, không build) cho Công ty TNHH Truyền thông Minh Hưng.
Giao diện theo bộ quy tắc [ui-ux-pro-max](https://github.com/dekitproject/ux-ui-promax-skill): B2B Service – Trust & Authority + Minimal, navy `#0F172A`, CTA cam `#EA580C`, font Be Vietnam Pro.

Chạy thử: `python -m http.server 5173` rồi mở http://localhost:5173

Việc cần làm: thay 3 thẻ "Dự án tiêu biểu" trong `index.html` bằng dự án thật.
